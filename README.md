# BACnet B-SCHUB (BACnet/SC Hub) — C++ example (planned)

Part of the CAS BACnet Stack **BACnet profile example series** — one self-contained
C++ tutorial per ASHRAE 135 Annex L device profile.

> **Status: planned.** This repository currently holds the implementation plan
> only. See [`docs/plan.md`](docs/plan.md) for the design (required BIBBs, objects,
> shared features, build steps). The example code (`main.cpp`, vendored `common/`,
> the `cas-bacnet-stack` submodule, CMake, full README) is scaffolded from that
> plan, following the
> [B-SS reference](https://github.com/chipkin/BACnetProfileExample-B-SS-CPP).

It will implement the **B-SCHUB (BACnet/SC Hub)** profile and nothing more, so it stays a
clean, copy-paste tutorial. Example source is CC0-1.0; the CAS BACnet Stack is a
separate commercial product.
