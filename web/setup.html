How BACnet/SC trust works

Every BACnet/SC connection is TLS 1.3 with mutual authentication: the device and the hub each show a certificate, and each accepts the other only if a CA (certificate authority) it trusts signed it.

  1. The device needs its own operational certificate (opr-*.pem) and private key, signed by the hub's CA - plus the CA certificate iss-1.pem, to check the hub.
  2. The hub needs nothing new for each device: it trusts every certificate its CA signed, right away.
  3. The file names follow CARI (ANSI/ASHRAE 135-2024 Annex AA.2), the layout BACnet uses to carry certificate requests to a CA and certificates back: csr- (request), opr- (certificate), key- (private key), iss-1 (issuer).
