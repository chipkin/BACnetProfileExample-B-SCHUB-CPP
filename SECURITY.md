# Security

This repository is an **example** of using the CAS BACnet Stack to build a
BACnet/SC hub, for evaluation and testing only. Its demo certificates
(`certs/`) are public: never use them, or this example, to protect a real
network.

## Reporting a vulnerability

Please report security problems privately to **support@chipkin.com** with
"Security" in the subject - not in a public issue. Include the version
(`BACnetExampleBSCHUB --version` prints the example's and the CAS BACnet
Stack's versions), the platform, and how to reproduce the problem. We will
acknowledge your report and let you know what we will do about it.
